# ETCアナライザー 親UI

`bat/00_ETC_launcher.bat` をダブルクリックすると、ブラウザ不要のPython / PyQt6製ランチャーが開きます。既存のセットアップで同梱Python環境を用意してから使用してください。

17ツールを番号順に一画面に表示し、アイコンを含むカード全体から各バッチを起動します。画面は最大化して開き、説明とアイコンの大きさはウィンドウサイズに合わせて調整します。1280×720以上の画面を推奨します。

「デスクトップに配置」でWindowsのデスクトップに「ETCアナライザー」のショートカットを作成します。ショートカットは同梱のpythonw.exeを使うため、親UI用のコンソールは表示しません。インストールフォルダを移動した場合は、新しい場所でバッチを開き、ショートカットを作り直してください。

起動対象や説明文は `src/common/launcher_catalog.py` で管理します。実行時の作業フォルダはインストールフォルダです。バッチの出力は `logs/launcher_*.log` に保存されます。バッチが不足している場合はカードに表示し、クリック時に不足ファイルを案内します。

親UIを閉じても、起動済みのツールは終了しません。各ツールの入力選択・保存・分析手順は従来どおりです。

デザイン参考: https://etc.roadlabo.com/tool-introduction-video/

確認: `runtime\python\python.exe tests\test_launcher.py`
