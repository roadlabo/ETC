# 15 エリア第1.5スクリーニング 操作説明

## 目的

第1スクリーニングで抽出した完全トリップCSVから、指定した分析区域を通行した部分だけを切り出します。

第1.5スクリーニングの役割は **エリア内サブトリップCSVを作ることだけ** です。OD表、交差点パフォーマンス、ルートパフォーマンスは既存の後段プログラムで処理します。

主出力は、第2スクリーニングと同じ考え方で **1サブトリップ1CSV** です。何十万トリップ規模でも扱えるよう、全トリップ点列を1つのExcelや1つの巨大CSVへまとめる設計にはしていません。

## 第1、第1.5、第2スクリーニングの関係

- 第1スクリーニング: 対象2次メッシュに関係する完全トリップを、運行IDごとのCSVに整理します。
- 第1.5スクリーニング: 第1出力から、分析区域の内側だけをサブトリップとして切り出します。
- 第2スクリーニング: 第1.5出力のCSVフォルダを入力にして、交差点やルートなど具体的な条件でさらに抽出します。

## 正式区域と分析区域

- 正式区域: 政策・計画・分析上の正式な対象区域です。
- 分析区域: 外周道路を含めて切り出すための解析用区域です。

分析区域は、正式区域から標準30m外側へ広げて作成できます。30mは初期値で、エリア設定画面で変更できます。生成後は地図上で手作業修正できます。

## エリア設定

起動:

```bat
bat\15_area_builder.bat
```

操作:

1. `正式区域を編集` を選び、地図をクリックして正式区域のポリゴンを作成します。
2. 必要に応じて頂点をドラッグして修正します。
3. `バッファ` に距離を入力し、`正式区域から分析区域生成` を押します。
4. `分析区域を編集` を選び、外周道路が入るように頂点を調整します。
5. `GeoJSON保存` で `15_area.geojson` として保存します。保存時に自己交差などを確認します。

## GeoJSON構造

1つのFeatureCollectionに次のFeatureを保存します。

- `properties.area15_role = official_area`: 正式区域のPolygon
- `properties.area15_role = analysis_area`: 分析区域のPolygon

古いGeoJSONに点や線の追加Featureが含まれていても、第1.5スクリーニングでは無視します。

## 第1.5スクリーニングUI

起動:

```bat
bat\15_UI_area_screening.bat
```

画面で指定するもの:

- 第1スクリーニングCSVまたはフォルダ
- エリアGeoJSON
- 出力フォルダ
- サブフォルダも含めるか
- 短距離サブトリップ除外しきい値
- 短時間サブトリップ除外しきい値
- 短時間再流入・再流出の統合秒数

前回設定はユーザーのホームフォルダに `.etc_area15_screening_ui.json` として保存・復元されます。

## コマンドライン実行

UIを使わずに実行できます。

```bat
runtime\python\python.exe src\15_area_screening.py --input "D:\_EtcData\out(1st)" --area "D:\_EtcData\15_area.geojson" --output "D:\_EtcData\15_result" --recursive
```

## 入力データ

第1スクリーニング出力の様式1-2互換CSVを使用します。ヘッダなしを前提とし、既存の第2スクリーニングと同じ列位置を使います。

- 運行日: index 2
- 運行ID: index 3
- GPS時刻: index 6
- トリップ番号: index 8
- 起終点フラグ: index 12
- 経度: index 14
- 緯度: index 15

日時は `YYYYMMDDHHMMSS` を基本とします。日時欠損、座標欠損、点数不足のトリップは除外一覧に記録します。

## 境界交点と時刻補間

連続する2点を線分として扱い、分析区域境界との交点を求めます。交点の緯度・経度は線分上の位置から線形補間します。交点時刻は、前後2点間の線分上の比率で補間します。

切り出したCSVでは、1行目の起終点フラグを `0`、最終行を `1`、途中行を空欄に正規化します。これにより、後続の第2スクリーニングが1サブトリップを1トリップとして扱えます。

## GPS誤差対策の設定

次の設定を持ちます。

- 短距離除外: 分析区域の端をかすめただけの短い線分を除外します。初期値は10mです。
- 短時間除外: ごく短時間だけ区域内に入った断片を除外します。初期値は5秒です。
- 短時間再流入統合: GPSの揺れで一度外へ出たように見える断片を、指定秒以内なら1つのサブトリップにつなげます。初期値は10秒です。
- 異常座標、日時欠損、点数不足は除外一覧へ記録します。

分析区域はあらかじめ余裕を持って外側に設定する運用のため、境界付近許容距離はUIには出していません。通常は0mとして扱います。

## 出力ファイル

- `15_area_subtrip_csv/`: エリア内に切り出したサブトリップCSVの保存フォルダ。境界交点の人工点を含め、元の様式1-2互換の16列で保存します。
- `15_subtrip_summary.csv`: 1サブトリップ1行の索引表。各サブトリップCSVのパス、開始時刻、終了時刻、所要時間、距離などを持ちます。
- `15_excluded_trips.csv`: 除外トリップと理由。
- `15_multi_entry_trips.csv`: 1トリップで複数回出入りした一覧。
- `15_subtrip_check.geojson`: 地図確認用のサブトリップLineString。大量データでは先頭側の一部のみ出力します。
- `15_area_screening_settings.json`: 解析条件の記録。
- `15_area_screening_log_YYYYMMDD_HHMMSS.txt`: 件数ログ。

## 後段での使い方

第2スクリーニング、交差点パフォーマンス、ルートパフォーマンスへ進む場合は、入力フォルダに第1.5出力の `15_area_subtrip_csv/` を指定します。

OD表を作る場合は、後段のOD系プログラムで処理します。境界部をゾーンとして扱いたい場合は、`12_polygon_builder` で必要なエリアを作成してからOD集計へ渡します。

## トラブルシューティング

- GeoJSONエラー: `official_area` と `analysis_area` が両方あるか確認してください。
- 抽出ゼロ: 分析区域が第1スクリーニング出力の座標範囲と重なっているか確認してください。
- 短い出入りが多い: 短距離除外、短時間除外、短時間再流入統合を調整してください。
- UIが起動しない: `logs\15_UI_area_screening_console.log` を確認してください。
