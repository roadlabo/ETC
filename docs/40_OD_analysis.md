# 40 OD分析

親ランチャーの「40 OD分析」、または `bat/40_UI_od_analysis.bat` から起動します。
様式1-3OD／トリップODをトグルで切り替え、ODリスト、ODマトリクス、ODヒートマップ、ゾーン別発生・集中マップを一つの画面で扱います。

## 2つのOD方式

| 方式 | O・Dの定義 | 必要な入力 |
|---|---|---|
| 様式1-3OD | 様式1-3に記録された元トリップの起終点 | スクリーニングCSV＋様式1-3 ZIP |
| トリップOD | 入力CSV内の各トリップの最初行・最終行の座標 | スクリーニングCSVのみ |

左上の2分割トグルで切り替えます。読み込んだデータ・集計結果・対象日設定は方式別に保持します。トグルだけで方式の異なる座標を混ぜたり置き換えたりはしません。

## 操作

1. プロジェクトを選びます。親ランチャーと同じ共通設定を使用します。
2. OD方式を選び、第1・第1.5・第2スクリーニング済みCSVのフォルダを指定します。様式1-3ODの場合はZIPフォルダも指定し、選択方式の「リストを作成」を押します。「2方式のODリストをまとめて作成」なら同じ入力から両方を作れます。下位フォルダも検索します。
3. 開始日・終了日・曜日を確認します。「対象日を個別に選択」で欠損日などを除外できます。初期期間は読み込んだODリストの最初から最後の運行日です。
4. 12で作成したCSVをプロジェクトの `12_ゾーニングデータ` に置き、「集計してマップを表示」を押します。
5. タブでOD表、起終点ヒートマップ、ゾーン別発生・集中マップを切り替えます。地図はドラッグ・ホイールで移動・拡大できます。別方式の結果も欲しい場合はトグルを切り替えて集計します。一度集計した結果はトグルで再表示できます。
6. 配色などを調整し「JPEG画像を保存」を押します。「出力フォルダを開く」で結果を確認できます。

## 集計の定義

- キーは **運行日＋運行ID＋トリップ番号**。別日の同一ID・番号を混同しません。IDの先頭ゼロを保持します。
- **様式1-3OD**では、同じ元トリップが複数CSVや第1.5の複数サブトリップに含まれていても1件です。第1.5を入力にしても様式1-3の元トリップの座標を使います。
- **トリップOD**では、CSV内で運行日・ID・番号が連続する区間ごとに最初行をO、最終行をDとします。第1スクリーニングの1ファイルに複数トリップがあっても分けて出力します。並べ替えはせず、入力の行順を使います。
- 第1.5の別々のサブトリップは、同じ元トリップ番号でもそれぞれの切り出し区間の起終点を保持します。入力行の内容が完全に一致するコピーは重複除去します。1行のみのトリップはO=Dです。
- 最初行・最終行の座標が不正な場合、途中の有効点で置き換えません。`INVALID_COORDINATES`としてODリストに残し、集計時に除外します。経度・緯度は様式1-2のO列・P列を使用します。
- 様式1-3はZIP内の `data.csv` を優先します。なければCSVメンバーを走査します。ZIP名に8桁の運行日がある場合は対象運行日のZIPに絞ります。日付のない名前は全件照合します。
- ODリストのstatusは `OK`、`MISSING_OD`（照合なし）、`CONFLICT`（同一キーの様式1-3座標が競合）です。座標が欠損・非数値・範囲外の行は集計時に除外します。
- OD表と両マップは、同じ対象日・status・座標検証を通ったトリップを使います。表の合計とマップの母集団を揃えます。
- **日平均＝採用トリップ数÷UIで選んだ対象日数**。ゼロ件の日も分母に入ります。欠損日をゼロ交通として扱わないよう、個別選択で除外してください。
- 日平均の単位は「トリップ/日」。プローブサンプルの集計であり、全車両交通量への拡大推計は行いません。
- ポリゴン境界を含めます。異なるゾーン名に重複する点は「【ゾーン重複】」、どのゾーンにも入らない点は「【区域外】」としてOD表に残します。固定都市の東西南北分類は行いません。
- 全ゾーンをOD表に表示します。0件のゾーンも省略しません。同名の複数ポリゴンは同一ゾーンとして集計します。
- 既存リストは同じ方式のCSVを複数読込できます。方式を混在させると停止して通知します。方式列のない旧ODリストは様式1-3ODとして扱います。トリップODには`od_method=trip`と`trip_instance`（区間識別子）が必要です。

## 地図とJPEG

**ODヒートマップ**は起点／終点、配色、不透明度、上限/日、半径、ぼかし、表示倍率を調整できます。近接点の影響を重ねた相対的な密度表示です。色は絶対交通量を表しません。

**ゾーン別発生・集中マップ**は各ゾーンの発生／集中トリップ数を日平均にして塗り分けます。配色、不透明度、上限/日、対数配色、ラベル表示を変更できます。区域外・重複は地図上のポリゴンには加算せず、OD表に別掲します。

- `上限/日=自動` は表示対象ごとに自動設定します。OとDを同じ色尺度で比較したい場合は同じ上限を手入力してください。
- JPEGは**画面内の地図領域のサイズ**で保存します。大きい画像が必要ならウィンドウを広げてください。地図・凡例・期間・出典表記を含みます。背景タイルが表示されてから保存してください。
- 起終点は `【様式1-3OD】ODheatmap(1).jpg` または `【トリップOD】ODheatmap(1).jpg`、ゾーン別は `【方式名】ODzoneheatmap(1).jpg`です。方式ごとに自動連番を付け、既存ファイルは上書きしません。地図の凡例にも方式名を表示します。
- 同名のJSONに描画係数・対象日・画面サイズを記録します。HTMLは集計時の初期表示、JPEGは保存時の表示です。
- Leafletと密度描画を同梱し、Playwrightや追加ブラウザのインストールは不要です。背景は保存済み地理院タイルを優先し、なければオンラインで取得します。両方なければ白地図になります。

## 出力

出力先はすべて **`プロジェクト/40_OD分析/` 直下**です。すべてのファイル名に `【様式1-3OD】` または `【トリップOD】` を先頭に付けます。集計結果は日時を加えて再実行時の結果を区別します。

- `【方式名】od_list_日時.csv`：1行1トリップ（様式1-3ODは元トリップ、トリップODは切り出し区間）。UTF-8 BOM。
- `【方式名】日時_od_matrix(all).csv`：全期間OD表、行列合計付き。
- `【方式名】日時_od_matrix(perday).csv`：日平均OD表、行列合計付き。
- `【方式名】日時_zone_production_attraction.csv`：ゾーン別の発生・集中、合計と日平均。
- `【方式名】日時_analysis.json`：OD方式・対象日・分母・採用／除外件数・ゾーン判定ルール。
- `【方式名】日時_sources.json`：入力ODリストの一覧。
- `【方式名】日時_heatmap.html` / `【方式名】日時_zones.html`：集計時の地図。
- 手動保存した連番JPEGと描画条件JSON。

処理中も画面は応答し、「中止」で中断できます。実行中に画面を閉じるとまず中止を要求します。処理が止まってから閉じてください。
