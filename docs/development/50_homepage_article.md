# 50_経路分析：対象路線の「通過交通」と実際の走行経路を見える化

> 2026年9月12日公開

## まず、50で分かること

50は、ある道路を使った車について、**地域の中に用事があって来た車なのか、地域を横切って別の場所へ抜けた車なのか**を分けて見るツールです。

たとえば、商店街を含む区域を設定し、その区域を通る幹線道路を選びます。50を実行すると、その道路を使った車のうち、どれくらいが区域内で出発・到着しているか、どれくらいが区域を通り抜けたか、通り抜ける車がどの道を使ったかを確認できます。

## エリアビルダーとGateから始めます

最初に、エリアビルダーで「ここを地域として調べる」という**分析区域**を地図上に作ります。分析区域は、中心市街地や観光地など、調べたい地域を少し余裕を持って囲んだ範囲です。

その後の第1.5スクリーニングは、車が分析区域の境界を横切った位置を計算し、14で手動指定した最寄りの**Gate（ゲート）**へ割り当てます。Gateは実際の門ではなく、「地域へ入った場所・出た場所」の目印です。50は、このGateを使って、地域に用事がある車と地域を通り抜けた車を分けます。

14のエリアビルダーで地域の範囲とGateを手動指定します。後の15・50では同じGateの位置・番号を使用し、自動で新しいGateを作りません。

## 初めて出る言葉の説明

| 言葉 | このページでの意味 |
|---|---|
| **分析区域** | 調べたい地域を囲んだ範囲です。中心市街地、観光地、住宅地など、目的に合わせて14で設定します。 |
| **対象路線** | 今回「この道路を使った車」を調べるために選ぶ道路です。10で線として作ります。 |
| **トリップ** | 1台の車の連続した移動記録です。ETC2.0プローブデータにある位置と時刻の並びを、ここでは1回の移動として扱います。 |
| **区域内サブトリップ** | トリップのうち、分析区域の中に入っている部分だけを切り出した移動記録です。15で作ります。 |
| **Gate（ゲート）** | 車が分析区域へ入る・出る位置として記録した、区域境界上の通過点です。出入口の実物を意味するものではありません。 |
| **Inside（インサイド）** | 分析区域の内側です。記事や画面で短く表示するための表記です。 |
| **OD（オーディー）** | Origin / Destinationの略で、どこからどこへ移動したかという組合せです。50では主に「どのGateから、どのGateへ」の組合せを指します。 |
| **25mメッシュ** | 地図を25m四方の小さなマスに区切ったものです。どの道に車の移動が集まったかを見やすくします。 |

## この分析が生まれた背景

ある道路の交通量が多いことは分かっても、その車が地域内を目的地としているのか、地域を通り抜けているだけなのかは、単純な交通量集計だけでは分かりません。

同じ1,000トリップでも、地域内の施設や住宅を利用する交通が中心なのか、区域の外から入り別の出口へ抜ける交通が中心なのかによって、考えるべき対策は変わります。そこで50_経路分析では、15のエリア第1.5スクリーニングで作った区域境界のGate情報と、20のルート第2スクリーニングで抽出したトリップを結び付け、対象路線を利用した交通の性格と走行経路を整理します。

## 目的

対象路線を通った区域内サブトリップを、区域への入り方・出方で分類し、通過交通の割合、主なGate間OD、実際に使われた経路を地図と表で確認できるようにすることが目的です。

単に「何台通ったか」を示すだけでなく、次の問いに答えられる形にします。

- 対象路線の交通のうち、区域を通り抜ける交通はどの程度か
- 通過交通は、どのGateから入り、どのGateへ抜けているか
- 区域内を目的地または出発地とする交通はどの程度か
- 車両は区域内のどの道を実際に走っているか
- 特定のGate間ODが、どの経路へ集中しているか

## 4つの交通分類

分析区域の境界を横切る位置をGateとして記録し、各サブトリップの始点と終点を次の4種類に分類します。

| 分類 | 始点 → 終点 | 意味 |
|---|---|---|
| 通過交通 | Gate → Gate | 区域外から入り、別の境界側へ抜けた交通 |
| 外内交通 | Gate → Inside | 区域外から入り、区域内で終わった交通 |
| 内外交通 | Inside → Gate | 区域内から出発し、区域外へ出た交通 |
| 内内交通 | Inside → Inside | 区域内で出発し、区域内で終わった交通 |

ここでのInsideは、正式区域ではなく、第1.5スクリーニングで設定した分析区域の内側を意味します。

## 通過交通率の意味

通過交通率は、次の式で求めます。

**通過交通率 ＝ Gate→Gateのサブトリップ数 ÷ 対象路線を通った全区域内サブトリップ数**

たとえば対象路線を通った区域内サブトリップが1,000件あり、そのうちGate→Gateが420件なら、通過交通率は42%です。

この値の単位は区域内サブトリップです。同じ車両や元トリップが複数回区域へ出入りした場合は、第1.5スクリーニングの再流入統合設定に従います。したがって、車両の実台数や道路交通センサスの交通量と同じ意味ではありません。

## この分析で分かること

### 1. 対象路線の役割

通過交通率が高ければ、対象路線が広域的な移動や区域の通り抜けに多く使われている可能性があります。外内・内外・内内交通が多ければ、区域内の施設、業務、居住などと結び付いた利用が多い可能性があります。

### 2. 主な流入・流出方向

Gate間ODランキングから、どの入口からどの出口へ向かう通過交通が多いかを方向別に確認できます。通過交通内の割合と、対象路線の全交通に占める割合を並べて表示します。

### 3. 実際に選ばれた経路

25mメッシュの経路地図では、トリップの点列を10m間隔で補いながら、各トリップが通ったセルを1回ずつ数えます。色が濃いセルほど、その表示グループの中で多くのトリップが通った場所です。

### 4. 特定ODの経路集中・分散

地図右上で特定のGate間ODへ切り替えると、その入口・出口の組合せだけを表示できます。同じODでも経路が一本に集中しているのか、複数路線へ分散しているのかを確認できます。

## こんな検討に効果的です

- 中心市街地や観光地で、来訪交通と通過交通を分けて考えたい
- バイパス、環状道路、迂回路の必要性や使われ方を確認したい
- 対象路線の交通が、どの区域境界方向と結び付いているかを把握したい
- 道路整備や交通規制の前後で、通過交通率や利用経路の変化を比較したい
- 特定のGate間ODが生活道路へ流入していないか確認したい
- ルートパフォーマンス分析の結果について、遅れが生じている交通の経路背景を補足したい
- 地域内交通を確保しながら、通り抜け交通への対策を検討したい

この分析だけで整備効果や因果関係を確定するものではありません。期間、曜日、区域、対象路線、抽出条件をそろえて比較し、現地状況や交通量調査と合わせて判断してください。

## 分析前に必要な準備

正式な通過交通率を出すには、次の順でデータを作成します。

1. **10_ルートファイル作成**で対象路線を作成する
2. **14_エリアビルダー**で正式区域・分析区域・Gateを設定し、**15_エリア第1.5スクリーニング**で区域内サブトリップとGate割当・由来情報を作る
3. **20_第2スクリーニング（ルート）**で、第1.5出力から対象路線を通ったトリップを抽出する
4. **50_経路分析**で路線別の交通分類と経路地図を作る

14では分析区域を外周道路が含まれるように設定し、Gateを手動で置いてください。境界と軌跡の交点は最も近い指定Gateへ割り当てます。

## 操作方法

### STEP 1　50を起動する

`bat/50_UI_route_path_analysis.bat` をダブルクリックします。黒地と緑を基調とした「50 経路分析 — ルート通過交通」の画面が開きます。

### STEP 2　プロジェクトフォルダを選択する

画面左側の「プロジェクトフォルダを選択」を押し、10・15・20の結果が入ったプロジェクトフォルダを選びます。

選択すると、区域ファイル、analysis_area、第1.5スクリーニング由来情報、ルート第2スクリーニング結果を自動確認します。必要な情報が揃っていない場合は、画面に警告が表示されます。

### STEP 3　分析対象路線を選択する

路線一覧から1路線を選びます。選択した路線の対象トリップ数と、第1.5スクリーニング由来として正式分析できる状態かを確認してください。

路線を変更すると、前の路線の画面上の結果は消去されます。成果物は路線別フォルダに保存されます。

### STEP 4　分析を実行する

「分析を実行」を押します。実行時に、各CSVと索引情報の対応、CSVの内容が途中で変わっていないか、Gateマスター、分析区域が同じ処理系列のものかを検証します。

分析が完了すると、画面右側に次が表示されます。

- 対象トリップ数
- 通過交通数
- 通過交通率
- 外内・内外・内内・通過交通の分類表
- 主要なGate間OD

### STEP 5　HTMLレポートと経路地図を開く

「HTMLレポート・経路地図を開く」を押します。レポートでは分類別の件数・割合、Gate間ODランキング、25mメッシュ経路地図を確認できます。

地図右上のレイヤー切替から、次を選べます。

- 全交通
- 通過交通
- 外内交通
- 内外交通
- 内内交通
- 指定Gate間OD

セルにマウスを合わせると、トリップ件数と、その表示グループ内での割合が表示されます。最初は全交通で主要経路を確認し、次に通過交通、最後に主要Gate間ODへ絞ると流れを読み取りやすくなります。

## 結果の読み方

### 画面上部の3つの数字

- **対象トリップ**：選択路線を通った区域内サブトリップの総数
- **通過交通**：そのうちGate→Gateと判定された件数
- **通過交通率**：対象トリップに占めるGate→Gateの割合

### Gate間ODランキング

- **トリップ数**：そのGate間を移動した件数
- **通過交通内割合**：通過交通だけを100%としたときの割合
- **全交通内割合**：対象路線の全交通を100%としたときの割合

「通過交通内割合」が高いODは、通過交通の主要方向です。「全交通内割合」も高ければ、対象路線全体の性格を左右する大きな流れと考えられます。

### 25mメッシュ経路地図

各セルの割合は、現在選んでいる交通グループを分母にします。全交通の地図と特定Gate間ODの地図では分母が違うため、色の濃さを画面同士で単純比較せず、セルに表示される件数も合わせて確認してください。

## 出力ファイル

結果はプロジェクト内の `50_経路分析/対象路線/` に保存されます。

- `50_report.html`：分類表、Gate間ODランキング、経路地図をまとめたレポート
- `50_map.html`：経路地図
- `50_trip_classification.csv`：各トリップの始点・終点種別と交通分類
- `50_path_summary.csv`：分類別集計
- `50_gate_od.csv`：Gate間ODランキング
- `50_mesh.csv`：25mメッシュごとの件数・割合

## 正式値にならない場合

第1.5由来情報、分析区域のハッシュ、各CSVとsidecar、Gateマスターの一致が確認できない場合、画面は「正式値無効」と表示します。旧形式の平置きCSVなどは、参考として全経路を表示できる場合がありますが、正式な通過交通率や交通分類には使えません。

正式分析が必要な場合は、同じプロジェクト内で15の第1.5スクリーニングから20のルート第2スクリーニングを作り直し、その結果を50へ渡してください。対象トリップが0件の場合も正式率は計算しません。

## 注意点

- 軌跡の点と点の間は直線で補間しています。道路ネットワークへ吸着するmap matchingではありません。
- GPS誤差や取得間隔により、実際には通っていない近接道路へメッシュがかかることがあります。
- Gateの位置と番号は14で保存した指定を使います。比較分析では同じ区域を使ってください。
- 期間、曜日、路線抽出半径などの条件が違う結果は、割合だけで単純比較しないでください。
- 通過交通率はETC2.0プローブデータに含まれるサブトリップの構成率です。地域の全交通量へ拡大解釈する場合は、サンプル特性を考慮してください。

50_経路分析は、対象路線を「何台が通ったか」から一歩進めて、「どのような交通が、どこからどこへ、どの道を使ったか」を説明するためのツールです。通過交通対策、道路ネットワークの役割確認、整備前後比較などでご活用ください。
