# 14 エリアビルダー

`bat/14_area_builder.bat` で正式区域・分析区域を作成します。第1.5スクリーニングの番号は15です。

## プロジェクト内の保存先

```text
プロジェクト/
├─ 12_ゾーニングデータ/
│  └─ 任意名.csv                 ← 12 ポリゴンビルダー（内部ゾーン）
├─ 14_エリアデータ/
│  └─ 14_area.geojson            ← 14 エリアビルダー（正式区域・分析区域）
├─ 15_エリア第1.5スクリーニング/
├─ 20_第２スクリーニング(ルート)/
└─ 50_経路分析/
```

12・14ともEdgeまたはChromeで開き、「プロジェクトを選択」でプロジェクトフォルダを指定します。保存すると上記のサブフォルダを自動作成してファイルを書き込みます。ブラウザのフォルダアクセス許可が必要です。画面に保存先が表示されます。

14では正式区域を描画し、バッファから分析区域の下書きを作成して調整します。保存するGeoJSONの属性は `area14_role=official_area` と `area14_role=analysis_area` です。

15の画面ではプロジェクトを選ぶと `14_エリアデータ/14_area.geojson` を自動指定します。CLIは `--project-dir` で同じファイルを読み込み、従来の `--area` によるファイル直接指定も使えます。50も同じ14のファイルと12のゾーニングCSVを確認します。不足時は各ビルダーでの作成を案内します。

## 既存プロジェクトの移行

旧 `12_エリアデータ/15_area.geojson` は、内容を編集せず `14_エリアデータ/14_area.geojson` へ移動・改名してください。旧 `area15_role` 属性も読み込めるため、ファイル内容のハッシュを維持すれば既存20の区域同一性チェックも通ります。区域を編集して保存し直した場合は15・20から再実行してください。

12で作成したゾーニングCSVは `12_ゾーニングデータ` に移動します。プロジェクト直下や14のフォルダに置いたCSVは、50の内部ゾーンとしては読み込みません。

起動バッチは `14_area_builder.bat`、HTMLは `14_area_builder.html` です。旧15番のエリアビルダー起動ファイルは14番に改名しました。
