# 14 エリアビルダー

`bat/14_area_builder.bat` で正式区域・分析区域と手動ゲートを作成します。Pythonの画面が開き、最初にプロジェクトフォルダを指定します。第1.5スクリーニングの番号は15です。

## プロジェクト内の保存先

```text
プロジェクト/
├─ 12_ゾーニングデータ/
│  └─ 任意名.csv                 ← 12 ポリゴンビルダー（内部ゾーン）
├─ 14_エリアデータ/
│  └─ 14_area.geojson            ← 14 エリアビルダー（正式区域・分析区域）
├─ 15_エリア第1.5スクリーニング/
├─ 20_第２スクリーニング(ルート)/
└─ 50_経路分析/
```

14は `src/14_area_builder.py` のPython画面で動き、保存先の `14_エリアデータ` を自動作成して直接書き込みます。ダウンロードフォルダやブラウザのフォルダアクセス機能は使用しません。プロジェクト内に既存のGeoJSONがあれば区域・ゲートを自動読込し、画面に保存先の絶対パスを表示します。HTML単体を開いた場合はBATからの起動を案内します。

12のポリゴンビルダーは引き続きEdgeまたはChromeでプロジェクトを選び、`12_ゾーニングデータ`へ保存します。

14では正式区域を描画し、バッファから分析区域の下書きを作成して調整します。「ゲートを追加」に切り替え、地図上の出入口をクリックしてください。ゲートはG01から番号を付け、常時表示します。ドラッグで移動、選択して削除・名前変更、戻す操作ができます。保存・再読込で番号と位置を保持します。

「参考：12 ゾーニングデータを読込」では12のCSVを灰色の参照ポリゴン・頂点として重ねて表示できます。参考レイヤは編集・GeoJSON保存の対象外です。正式区域・分析区域の頂点を追加またはドラッグする際、参照ゾーンの頂点から15ピクセル以内ならその頂点へスナップします。ゲートの辺上スナップは従来どおり分析区域を優先します。

BATから起動した場合、GeoJSON・12参照CSVの読込ダイアログは選択中のプロジェクトフォルダを初期表示します。

保存するGeoJSONの属性は `area14_role=official_area`、`area14_role=analysis_area`、`area14_role=gate`（Point、gate_id、name）です。区域またはゲートが不足・不正なら保存しません。書き込みは一時ファイルから置き換え、失敗時に既存データを壊さないようにしています。

15と50は、分析区域の境界上の起終点を最寄りの指定ゲートへ割り当てます。距離上限はなく、同距離なら番号の小さいゲートを選びます。境界以外のINSIDE端点は内部ゾーンのままです。ゲートの自動生成・50m再集約は廃止しました。指定ゲートがなければ14での作成を案内して停止します。

15の画面ではプロジェクトを選ぶと `14_エリアデータ/14_area.geojson` を自動指定します。CLIは `--project-dir` で同じファイルを読み込み、従来の `--area` によるファイル直接指定も使えます。50も同じ14のファイルと12のゾーニングCSVを確認します。不足時は各ビルダーでの作成を案内します。

## 既存プロジェクトの移行

旧 `12_エリアデータ/15_area.geojson` は `14_エリアデータ/14_area.geojson` へ移動・改名してください。旧 `area15_role` 属性も読み込めます。ゲートがない旧データは14でゲートを追加して保存し、15→20→50を再実行してください。区域やゲートを変更して保存した場合も、区域ハッシュが変わるため15・20から再実行してください。

12で作成したゾーニングCSVは `12_ゾーニングデータ` に移動します。プロジェクト直下や14のフォルダに置いたCSVは、50の内部ゾーンとしては読み込みません。

起動バッチは `14_area_builder.bat`、HTMLは `14_area_builder.html` です。旧15番のエリアビルダー起動ファイルは14番に改名しました。

```bat
bat\14_area_builder.bat --project-dir "D:\PROJECT"
```
