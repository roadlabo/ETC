# 津山市オフライン地図の準備

地図編集画面は、最初に `src/tiles/gsi_pale/{z}/{x}/{y}.png` を読みます。タイルがない場所は、オンライン時だけ国土地理院の淡色地図を読み、オフライン時は白地図になります。Leaflet 本体も同梱版を使うため、CDN 接続は不要です。

## 初回準備

1. 国土数値情報などから取得した**津山市行政区域だけ**の Polygon / MultiPolygon GeoJSON を用意します。
2. `bat/00_津山市オフライン地図作成.bat` を実行し、GeoJSON のパスを入力します。
3. 作成後は `_EtcAnalyzer` フォルダー一式を対象 PC へコピーします。

標準のズーム範囲は 9～18 です。バッチは、指定済みの「調査結果マップ_完全オフライン」フォルダーに同じ `z/x/y.png` があれば、通信せずハードリンクまたはコピーして再利用します。指定場所が存在しない場合だけ国土地理院から取得します。

コマンドから範囲を小さくする例:

```bat
runtime\python\python.exe src\download_tsuyama_tiles.py 津山市.geojson --min-zoom 10 --max-zoom 16 --reuse "D:\既存地図"
```

行政界に接するタイルは四角形単位で保存されるため、市境付近の1枚には市外が一部含まれる場合があります。市域から離れたタイルは保存されません。国土地理院コンテンツ利用規約および出典表示を確認して利用してください。
