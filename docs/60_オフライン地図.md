# 60 オフライン地図作成

ETC2.0アナライザーの地図画面は、オンライン時は国土地理院の淡色地図を読みます。インターネット接続がない場合は `src/tiles/gsi_pale/{z}/{x}/{y}.png` の同梱タイルを読み、同梱タイルがない範囲は白地図になります。Leaflet 本体も同梱版を使うため、CDN 接続は不要です。

## 津山市街地用タイル

津山市街地用のタイルは作成済みです。通常利用では追加作業は不要です。

## 任意地域のタイルを作成する場合

`bat/60_オフライン地図作成.bat` をダブルクリックすると、スタンドアロン用地図データ作成画面が開きます。

画面では次の項目を指定します。

- 地図を残したい範囲: Polygon / MultiPolygon形式のGeoJSONを指定します。市町村界や調査区域の境界ファイルです。
- ズーム範囲: 標準は9から18です。広い範囲で18まで作ると容量が大きくなります。
- 既存タイル再利用: 過去に作った `z/x/y.png` 配置のタイルがある場合だけ指定します。空欄でも実行できます。

保存先は `src/tiles/gsi_pale` です。ここに保存されたタイルが、スタンドアロン利用時の背景地図として使われます。

この機能は国土地理院のタイルをダウンロードするため、起動時にインターネット接続を確認します。オフライン環境で起動した場合は「現在、オフライン環境です。インターネット環境で立ち上げなおしてください。」と表示します。

## コマンドから直接実行する場合

```bat
runtime\python\python.exe src\download_offline_tiles.py 任意地域.geojson --output src\tiles\gsi_pale --min-zoom 10 --max-zoom 17
```

既存の `z/x/y.png` 配置タイルがある場合は、`--reuse` で指定すると、通信せずハードリンクまたはコピーで再利用します。

```bat
runtime\python\python.exe src\download_offline_tiles.py 任意地域.geojson --output src\tiles\gsi_pale --reuse "D:\既存地図"
```

境界に接するタイルは四角形単位で保存されるため、境界付近の1枚には対象範囲外が一部含まれる場合があります。対象範囲から離れたタイルは保存されません。国土地理院コンテンツ利用規約および出典表示を確認して利用してください。
